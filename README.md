# 🧪 Sauce Demo Login Tests with Playwright

This is a **minimal automation project** built with [Playwright](https://playwright.dev/) to test the login functionality of [saucedemo.com](https://www.saucedemo.com).  
It contains two simple test cases in a single file and is perfect for beginners exploring end-to-end browser testing.

---

## ✅ Features

- 🔹 Uses Playwright Test Runner
- 🔹 One test file (`sauce-tests.spec.js`)
- 🔹 Two test cases:
  - ✅ Successful login
  - ❌ Failed login with wrong password
- 🔹 Headed and headless mode support
- 🔹 Designed for easy use in [Replit](https://replit.com) or locally
